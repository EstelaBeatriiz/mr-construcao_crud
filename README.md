Front-End — Sistema Comercial Mr. Construção

Aplicação front-end desenvolvida em React, TypeScript, Vite,para o sistema comercial do Mr. Construção

Autora
* Nome: Estela
* Curso / Turma: Curso Técnico em Informática
* Disciplina: Desenvolvimento Front-End

Módulos Implementados
* Módulo A — Produtos:Listagem com busca, cadastro, edição e exclusão com formulário reutilizável.
* Módulo B — Clientes: Listagem com busca, cadastro, edição e exclusão com dados de contato, endereço completo e ponto de referência e formulário reutilizável.
## Como Rodar o Projeto

1. Instale as dependências:
   npm install

2. Inicie o servidor de desenvolvimento:
   npm run dev
